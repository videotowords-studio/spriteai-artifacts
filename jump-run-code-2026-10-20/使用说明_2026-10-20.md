## 修改与再次导出

前置条件：本机安装 Node.js 22 或更新版本；需要重新裁片时，还需安装 Python 3 和 `source/requirements.txt` 中的 Pillow。现成裁片已包含在资料包中，直接修改动作不需要重新裁片。

1. 下载并解压完整资料，进入 `source/` 目录。
2. 修改 `animation.js` 中的动作与时间参数。
3. 运行 `npm run check` 检查动画。
4. 检查通过后，运行 `npm run render` 导出视频。首次使用 HyperFrames 时可能需要下载浏览器和渲染依赖。

需要重新裁片时，先替换 `source/assets/input-original.png`，再在 `source/` 运行 `python3 prepare_assets.py`。裁片轮廓和关节坐标针对本角色设置，换角色后需要同步调整。

独立网页的图片与动画代码已内嵌。修改 `source/` 不会自动更新独立网页，须同步重新打包。

## 动画方式与限制

原图拆成身体、前后手臂、前后腿，以代码计算关节位置和网格变形，再按固定时间渲染为视频。未使用 AI 图生视频。单图未提供的遮挡细节没有重新绘制，因此部分关节保留纸片动画的变形感。

视频采用米色场景背景。后续制作精灵序列帧时，可调用 `spriteAnimation.draw(t, true)` 直接渲染透明背景，再导出 PNG，避免视频压缩损失。`t` 的单位是秒；透明导出接口在 `window.spriteAnimation.ready` 完成后使用。
