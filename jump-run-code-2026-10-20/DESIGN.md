# 角色奔跑与跳跃动画

版本：1.0。生成、修改日期：2026-10-20（Asia/Shanghai）。

## Style Prompt
以用户提供的棕发、棕色外套、蓝色长裤、米白运动鞋角色为唯一人物视觉参考。保留原图像素边缘、面部和衣服纹理。轻快横版游戏动作演示：奔跑、蓄力、跃过小障碍、落地缓冲、继续奔跑。浅暖色场景，主体显著，背景克制。由原图裁片和可定位到任意时刻的骨骼变形驱动，不使用生成式视频。

## Colors
- #f5efdf：暖色天空。
- #dfd2b5：远景岩丘。
- #7a8c64：地面草边。
- #4d3630：轮廓与土层。
- #3e9ed1：原图蓝色长裤辅助色。

## Typography
成片不包含文字。离线网页控制栏使用系统字体，位于导出画布之外。

## Motion
6.4 秒，1280×720，30 fps。约 0.64 秒一次奔跑步态，左右腿反相。2.08 秒蓄力；2.26–3.46 秒腾空；3.46 秒落地。脚底接地、膝盖弯曲、手臂反向摆动、身体跟随。场景水平滚动。

## What NOT to Do
- 不改变角色脸部、头发和衣服设计。
- 不把整图平移冒充四肢奔跑。
- 不添加字幕、水印、介绍卡片。
- 不依赖随机数或真实时间决定导出画面。
- 不调用图生视频或图像生成模型。
